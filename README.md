# Budget Pro

Personal finance app — budgets, saving boxes, card balances, investments, net worth and rich charts.

**Open:** https://ahmedusamamowafy-sys.github.io/budget-pro/

- Installable on phones (Android: *Install app* · iPhone: *Share → Add to Home Screen*) and works offline.
- This repository contains **no personal data**. Each device keeps its data locally and syncs through the owner's private Google Sheet (protected by a secret key) — see *Admin → Data & sync* in the app.
